# 游戏内对话理解与自然语言处理系统

## 项目描述

游戏内对话理解与自然语言处理系统的bug修复项目。核心模块 `nlp/dialogue.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 输入理解完全没做NPC听不懂玩家说什么
- 意图识别完全没做只能匹配关键词
- 实体提取完全没做不能提取对话中的实体
- 对话状态完全没做不知道对话进行到哪里
- 回复生成完全没做NPC只会说固定的话

## 运行测试

```bash
python -m pytest tests/test_dialogue_understanding.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
